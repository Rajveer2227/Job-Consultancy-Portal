 💼 Job Consultancy Portal

A full-stack web application that connects job seekers with employers. This system enables candidates to browse and apply for jobs while allowing companies to post listings and manage applications. The portal also includes a backend admin panel for managing user and job data efficiently.



 📌 Overview

The Job Consultancy Portal simplifies the hiring process by providing a centralized platform for job opportunities and talent acquisition. It supports user account creation, job search with filters, resume uploads, and job posting functionalities. Admins can review, approve, or remove job listings and user profiles.



🛠️ Tech Stack

        Technologies  used                       

| Frontend     | HTML, CSS, JavaScript, Bootstrap       
| Backend      | PHP                                     
| Database     | MySQL                                   
| Hosting (Local) | XAMPP / WAMP                         

✅ Key Features

👤 User Registration & Login (Job Seekers and Employers)
 📝 Job Posting and Application System
 📄 Resume Upload and Profile Management
 🔍 Job Filtering by Category, Location, or Role
 📊 Admin Dashboard to manage job listings, users, and applications
 🖥️ Responsive UI using Bootstrap
